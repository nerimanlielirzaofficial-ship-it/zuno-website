ZUNO — PROFESYONEL WEB SİTESİ

Bu ZIP, Zuno için Türkçe, animasyonlu, mobil uyumlu web sitesi ön yüzünü içerir.

DOSYALAR
- index.html: Sayfa içeriği
- style.css: Tasarım ve responsive görünüm
- app.js: Mobil menü, kaydırma animasyonları ve tıklanabilir panel sekmeleri

GITHUB'A YÜKLEME
1. ZIP'i çıkart.
2. GitHub'da zuno-website deposunu aç.
3. Add file > Upload files seç.
4. Üç web dosyasını (index.html, style.css, app.js) depo ana dizinine yükle.
5. Commit changes ile kaydet. Vercel bağlıysa otomatik yayınlanır.

VERCEL
- Projeyi GitHub deposundan içe aktar.
- Framework: Other
- Build command: boş
- Output directory: boş veya ./ (arayüzün istediği seçeneğe göre)
- Deploy

ÖNEMLİ SINIRLAMA
Bu sürüm gerçek Discord yönetim paneli değil; profesyonel web sitesi ve etkileşimli DEMO panelidir. Paneldeki sayılar örnektir. Tıklanan sekmeler sadece örnek ekranı değiştirir, Discord sunucusunda işlem yapmaz.

Gerçek panel için ayrıca Discord OAuth2 girişi, güvenli backend/API, veritabanı ve sürekli çalışan discord.js botu kurulmalıdır. Bot token'ını asla HTML/JS dosyalarına veya herkese açık GitHub deposuna koyma.

GÜVENLİK
Verilen davet bağlantısı Administrator (Yönetici) izni içeriyor. Bu çok geniş bir izindir. Canlı kullanımdan önce botun ihtiyacı olan asgari izinlerle yeni davet bağlantısı oluşturman önerilir. Discord rol hiyerarşisi de geçerlidir.
