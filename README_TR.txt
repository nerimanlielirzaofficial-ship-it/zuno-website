ZUNO WEB SİTESİ - KURULUM

Bu paket, Zuno için Türkçe, mobil uyumlu ve animasyonlu bir tanıtım sayfasıdır.

DOSYALAR
- index.html: Ana sayfa
- styles.css: Tasarım ve animasyonlar
- script.js: Kaydırma animasyonları ve mobil menü

GITHUB'A YÜKLEME
1. ZIP dosyasını telefonda çıkar.
2. İçindeki index.html, styles.css ve script.js dosyalarını GitHub'daki zuno-website deposunun ana dizinine yükle.
3. Dosyalar public klasörünün içinde değil, depo ana dizininde olmalı.
4. Commit changes yap.
5. Vercel, GitHub değişikliğini algılayıp otomatik yeniden yayınlamalı.

VERCEL AYARI
Bu site düz HTML/CSS/JS kullanır. Framework preset: Other.
Build command: boş bırak.
Output directory: boş bırak (dosyalar depo kök dizininde olduğu için).
Install command: boş bırak.

ÖNEMLİ
Discord davet bağlantısı, OAuth2 ile giriş ve gerçek yönetim paneli henüz bağlanmamıştır. Sayfadaki panel görseli örnek tasarımdır; gerçek sunucu verisi göstermez. Bunlar sonraki geliştirme aşamasında güvenli sunucu tarafı koduyla eklenecektir.
